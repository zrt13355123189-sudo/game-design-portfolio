# 《代号：地形》｜系统与关卡设计案例

《代号：地形》是以地形改造为核心的回合制战棋项目。项目希望让玩家不只比较单位数值，还能通过改变高低关系、射程与安全空间，主动塑造接下来的交战局面。本页汇集目前可公开的阶段性设计材料，重点呈现我在系统规则、单关结构、敌人配置和实机迭代中的思考；它不是完整游戏说明书，也不代表所有设定已经定稿。

当前展示重点是“面粉关”单关 Demo：玩家可在开局选择推进方向，在厨房争夺有限面粉，用于烹饪强化或制造封闭空间爆炸，最终寻找突破城堡与 Boss 房的方法。白盒规则与关卡机制已形成可运行的验证基础；敌军节奏、Boss 房处理方式与数值平衡仍在持续调整，正式界面、美术及公开试玩材料将随项目推进补充。
