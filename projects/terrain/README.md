# 《代号：地形》｜系统与关卡设计案例

**项目定位：**独立回合制战棋；**个人职责：**主策划，负责核心玩法、系统规则、单关结构、敌人配置与阶段性实机迭代；**当前展示：**以“面粉关”验证地形改造能否持续产生可推演的战术选择。玩家可在战前有限地改造地形，局内继续建造或破坏高台；高度同时改变攻击环、交战风险和未来回合的阵地价值。敌方也会利用地形，因此玩家既能主动布势，也必须预判自己所依赖的安全格会如何变化。

“面粉关”把这一规则放进野外分线、厨房与城堡的连续体验：A 线先让玩家认识高台对击杀阈值的影响，B 线更早面对敌方高台火力；厨房的有限面粉可用于烹饪或封闭空间爆炸，敌方厨师同样争夺资源；Boss 房则把角塔施工和行动结束时的警戒攻击叠加为一场需要观察、诱导与拆解的攻坚。我的设计关注点不是规定唯一通关手顺，而是让不同路线各有风险与回报，并让敌人站位、技能和触发时机承担清晰职责。相关结论来自当前阶段的策划推演与人工实机，不能替代尚未开展的外部玩家验证。
