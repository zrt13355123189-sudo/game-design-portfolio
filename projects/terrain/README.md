## 项目目标与策划职责

项目希望把战棋中的“地图条件”转化为玩家能够主动修改的战术变量。高度会改变武器的攻击距离和近战关系，高层还会带来孤立、禁疗等代价；敌我双方都可能利用地形，因此建设不是固定开局仪式，而是一次关于行动成本、未来射程和阵地寿命的投资。战前地形改造、战中高台工事、技能与武器选择共同决定玩家如何解题，但关卡仍需保证不使用特定机制也存在可玩的基础路线。

我的工作覆盖整体循环与阶段目标拆解、系统规则与边界定义、关卡路线和敌群职责、配置与数值调整、最小局面实验、人工实机和方案复盘。技术实现只作为验证设计的手段，本作品集主要呈现能迁移到系统策划与关卡策划工作的部分：如何写清规则、组织体验、发现伪选择、控制复杂度，并把问题拆成可以落地和验收的内容。

## 为什么以“面粉关”作为当前切片

完整蓝图中的技能学习、角色关系、特殊棋子、地形蓝图与局外地形拼接，最终都要回到战斗中被尝试和验证。若局内战斗本身无法稳定地产生判断，外围系统只会扩大制作范围，不能建立项目核心。因此当前首先完成一张能够同时承载路线选择、有限资源、敌人职责、高台攻防和 Boss 压力的关卡，再让关卡暴露系统边界并反向修正规则。

面粉关由野外分线、厨房和城堡构成。A 线利用邻近的主动敌人和厨师烹饪形成引导与时间压力；B 线允许玩家在危险范围外布阵，并通过堵口敌人、远处高台单位和自然分批到场的敌军检验阵地复用问题。面粉既可被敌我烹饪，也能参与封闭空间爆炸，因此路线选择同时影响资源和后续战斗阈值。关卡不追求唯一标准手顺，而是让战前改造、战中施工、资源利用和基本走位成为不同层次的答案。

## 当前完成度与材料边界

高台、地形改造、敌我共享的基础交互与面粉相关机制已具备可运行基础；当前重点是继续打磨完整路线中的敌军节奏、数值阈值、Boss 房与信息呈现。复杂空间评分 AI 已因行为不可读、问题难归因和验证成本过高而停止继续开发。现阶段结论来自策划推演、最小局面实验、人工实机及项目内验收，尚无外部试玩数据。

后续将先稳定面粉关的完整战术节奏，再录制正式视频，并从基础教学和 B 线第一波中截取面试用试玩内容。长期的局外循环和玩家自选限制挑战属于方向规划，不计入当前 Demo 完成度；公开材料会继续区分已经成立的设计、正在打磨的内容和远期设想。
