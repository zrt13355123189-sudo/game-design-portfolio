# 《代号：地形》｜把地形改造变成战术抉择

《代号：地形》是一项回合制战棋设计实践。它关注的不是给既有战棋增加一个“建造”按钮，而是让地形参与攻击距离、安全格、击杀阈值与未来回合的行动安排：玩家可以事先布势，也要面对敌方改变高台后重画的威胁范围。我负责该项目的核心玩法、系统规则、单关结构与敌人配置的设计及阶段性实机迭代；本作品集重点展示策划判断，不以工程实现量作为成果叙述。

目前最能代表项目的是“面粉关”单关 Demo。它把开局分线、高台交战、厨房有限面粉的烹饪／爆炸互斥用途、敌方资源行动和城堡 Boss 房压力放进同一张地图，目的是验证玩家是否真的会在路线、站位、回合与资源之间作有意义的选择。制作基线、可编辑关卡编成及厨房机制／教学事件已分别通过阶段验收；敌军节奏、Boss 房解法和数值平衡仍在实机调整。面向首次接触者的信息界面、正式视听表现与可公开试玩包尚未完成，因此当前文档展示的是阶段性设计与验证，而非最终完成的游戏体验。

## 阅读路径

如果只有 5–10 分钟，请先读[主案例：从高台系统到面粉关](01_项目概览.md)。它说明项目从五月的整体循环蓝图，如何收束到一张可验证的战棋关卡，并用具体敌群与失败实验解释设计选择。希望继续了解系统规则时读[高台与地形博弈](02_核心系统_高台与地形博弈.md)；关注关卡策划工作时读[面粉关设计](03_关卡设计_面粉关.md)；想看问题如何改变方案时读[设计迭代案例](04_设计迭代案例.md)。约 2 分钟的视频和约 30 分钟的代表性试玩切片仍待制作，届时会在本页放置可直接访问的入口。

## 进度与材料边界

五月的《系统策划案切片》Part 2 记录了“战前地形与流派装配—局内战斗与探索—局外家园生态—职业流派培养”的长线游戏循环，是理解项目设计意图的历史蓝图，不等于这些局外系统已经落地。当前 Demo 有意只截取“战前选择—单关战斗—胜负反馈”的可验证片段，家园、招募、羁绊和长期养成不在本轮交付范围内。文中的数值、敌人站位和路线强度若仍在测试，均以“当前配置”或“待验证目标”表述；后续出现新结论时会保留设计问题与取舍逻辑，同时更新实际状态。
