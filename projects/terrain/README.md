## 玩家在游戏中做什么

基础战斗沿用传统日式战棋的回合结构。玩家选择角色移动，再决定攻击、治疗、使用物品或执行职业能力，并根据敌我射程、反击、追击和伤害阈值安排整队行动。《代号：地形》增加了两个直接影响地图的层次：**战前可以用有限额度改变部分格子的地形；战中可以由特定角色建造或破坏高台。**

高度会推动武器的最小、最大射程，近处目标可能因此进入盲区；高层还伴随孤立、禁疗等代价。敌人同样能够利用地形。队伍中的建筑师职业具备施工能力，玩家让建筑师搭建一处高台时，需要一起计算本回合少打一次的损失、之后能够覆盖多少敌人、敌人移动后的威胁，以及这处阵地还能安全使用几回合。战前改造、战中施工、武器和技能由此落到同一张地图上，共同决定一场战斗的解法。

## 当前为什么先做“面粉关”

完整蓝图还包括流派技能、角色关系、特殊棋子、地形蓝图与局外地形拼接。这些内容最终都要回到战斗：新技能需要在关卡中试用，角色关系奖励会改变编队，新的地形蓝图也需要进入后续地图验证。**关卡战斗承接了所有外围系统的反馈，因此它必须最先站得住。**

面粉关由野外分线、厨房和城堡组成。A 线用邻近的主动敌人把初见玩家引向厨房，敌方厨师会把有限面粉加工为全军增益，拖延时间会直接提高后续战斗阈值；B 线允许玩家在敌方危险范围外布阵，再通过堵口敌人、远处高台单位和自然分批到场的敌军检验阵地能否长期复用。面粉还可以参与封闭空间爆炸，因此玩家需要在烹饪、爆炸、路线速度和高台施工之间分配行动与资源。

## 当前完成度与个人工作

我负责整体循环与阶段目标拆解、系统规则和边界、关卡路线、敌群职责、数值与配置调整、最小局面实验、人工实机和方案复盘。目前高台、地形改造、基础战斗和面粉相关机制已经具备可运行基础；正在推进完整路线中的敌军节奏、数值阈值、Boss 房和信息呈现。复杂空间评分 AI 已经停止继续开发，原因是行为难以理解、问题难以归因，继续调试还会占用关卡配置时间。

现阶段没有外部试玩数据。接下来会先稳定面粉关的完整战术节奏，再录制正式视频，并从基础教学与 B 线第一波截取面试用试玩内容。局外完整循环和玩家自选限制挑战属于长期方向，不计入当前 Demo 完成度。
