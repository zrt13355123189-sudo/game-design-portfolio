## 推荐短目标

**到达地图右上方厨房，通过交互拾取一包厨房中的面粉。** 初始测试背包内的面粉不计入此目标。

这段体验约需 15–30 分钟，能够观察战前编成与部署、危险范围、敌军组激活、高台施工、树林与精确射程等主要系统。希望继续完整体验时，可以争夺厨房资源、进入城堡并完成 Boss 房战斗；熟练完整通关预计约 60 分钟。

建议优先保留建筑师、斥候和一名治疗角色。进入新的警戒区域前，可以按 `X` 查看全敌威胁，并用 `Tab` 固定关键敌人的实际威胁范围。更完整的按键、系统规则与分段攻略见[操作说明与攻略 PDF](《代号：地形》面粉关操作说明与攻略.pdf)。

## 这个版本展示什么

- **完整单关结构：** 40×30 地图覆盖户外 A / B 路线、厨房、城堡与 Boss 房；
- **地形系统：** 战前地形改造，以及局内高台的精确射程、近战工事、建造与拆除；
- **关卡机制：** 面粉拾取与撒布、粉尘爆炸、敌我共享的烹饪增益序列；
- **敌军职责：** 分组激活、治疗与道具使用、厨师搬运、角楼高台和 Boss 警戒攻击；
- **战前与信息交互：** 9 选 7 编成、流派调整、物品交换、运输队、危险范围和情报书。

本版本已经完成 Godot 导入与脚本校验、面粉关功能冒烟测试和导出程序启动测试。它用于验证系统设计与关卡设计，**不代表最终画面、音效和 UI 品质**；当前数值与敌人配置也尚未接受外部试玩反馈。
