# 原始工作文档｜阅读说明

> 建议阅读：先看 1 分钟说明，再按需打开单篇原稿
> 用途：核验关卡意图、制作拆解、迭代记录与验收方法

[返回项目主页](../README.md) · [项目概览](../01_项目概览.md) · [核心系统](../02_核心系统_高台与地形博弈.md) · [关卡设计](../03_关卡设计_面粉关.md) · [迭代复盘](../04_设计迭代案例.md)

**这里保留的是开发过程中的原始工作快照，用于佐证策划结论怎样进入关卡、配置与验收。** 文档维持原文，不为求职展示重新润色，因此包含开发路径、内部文件名、阶段任务和已经被后续迭代替代的表述；阅读作品集时，以四篇整理后的案例作为当前结论。

**部分原稿仍写有“高台每层通用加伤”等旧规则，这恰好记录了机制收窄前的阶段状态。** 当前公开口径已经移除基础高台的通用伤害，并将伤害收益集中到建筑师“高地应援”；建造与破坏始终是全员可用的通用操作，建筑师的差异是一次可以选择调整 1～2 层。原稿中的旧规则不代表现行版本。

## 遴选文档

### [01｜面粉关关卡策划案（原始文档）](01_面粉关关卡策划案_原始文档.md)

**这份文档记录关卡的空间结构、厨房资源、Boss 房、高台与路线博弈设想。** 它适合核验面粉关从“机制清单”走向完整关卡时考虑过哪些变量，也能看到部分旧结论如何被后续实机推翻。

### [02｜面粉关 Demo 体验基线与流程设计（原始文档）](02_面粉关Demo体验基线与流程设计_原始文档.md)

**这份文档定义完整 Demo 的玩家流程和交付边界。** 内容从标题页、战前准备、完整战斗到胜败结算，并说明熟练通关时长、目标玩家、存档与信息透明度等体验基线。

### [03｜阶段三：敌军节奏、Boss 房与数值平衡（共创记录）](03_阶段三敌军节奏与数值平衡_共创记录.md)

**这份文档记录关卡进入敌军与数值阶段后的连续判断。** 其中包含阈值推演、路线回测、树林简化和复杂空间 AI 的试验／回退，可用于核验迭代案例中的时间与决策依据。

### [04｜面粉关 Demo 验收矩阵（原始文档）](04_面粉关Demo验收矩阵_原始文档.md)

**这份文档把体验目标拆成可检查的完成条件。** 它覆盖战前准备、厨房、Boss 房、胜败流程、信息提示与试玩交付，用于约束“功能存在”和“玩家能够理解并完成”之间的差距。

## 阅读建议

**面试阅读无需从头通读原稿。** 系统岗位可在 01 和 03 中查看规则变化与失败方案；关卡岗位可在 01 和 02 中查看路线、资源和完整流程；希望确认执行方法时，再查看 04 的验收拆解。
