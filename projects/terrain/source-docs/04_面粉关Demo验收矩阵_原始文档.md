# 面粉关 Demo 验收矩阵

最后更新：2026-08-11  
对应总目标阶段：阶段 0 - 制作基线与范围冻结  
文档性质：功能、体验与发布验收依据

## 使用规则

- 本文档定义单关 Demo 的验收方向，不替代具体阶段的测试用例。
- 后续阶段执行计划应引用本表相关条目，并将其拆成自动测试与人工 QA 路径。
- `阻断` 表示未满足时不得进入公开试玩/录制版本；`重要` 表示应在发布前解决；`观察` 表示需要通过完整游玩收集结论。

| 类别 | 验收项目 | 通过标准 | 优先级 |
| --- | --- | --- | --- |
| 流程 | 正式入口 | 可从标题页进入简报、战前准备、战斗与结果页，并可返回标题 | 阻断 |
| 流程 | 胜败结算 | 击败 Boss 胜利；我方全灭失败；重开与返回标题无残留运行态 | 阻断 |
| 流程 | 局内存档 | 我方回合空闲时可保存到 3 个槽；读取后还原当前局面且继续本回合 | 阻断 |
| 编队 | 战前准备 | 七人部署、两人替换、流派选择、预设点位换位与地形配置都可完成 | 阻断 |
| 关卡 | 厨房可选性 | 不去厨房仍可通关；抢厨房资源可明显降低部分战术阈值或拓展解法 | 重要 |
| 关卡 | 敌方软狂暴 | 敌方烹饪会按共享增益表推进，并能明显提高追击、击杀或生存压力 | 重要 |
| 关卡 | 资源取舍 | 面粉用于烹饪与爆炸互斥；资源有限，不能无成本同时取得全部收益 | 阻断 |
| 关卡 | 粉尘爆炸 | 粉尘、封闭、热源、75% 最大 HP 真实伤害、不致死、高台拆除和时效规则均正确 | 阻断 |
| 关卡 | 厨师与友军教学 | 友军教学事件可稳定触发一次；厨师行为、事件锁定与恢复不造成回合卡死 | 阻断 |
| Boss 房 | 警戒攻击 | 行动结束后按实际范围追加一次攻击；不递归、不消耗行动、不触发反击或追击 | 阻断 |
| Boss 房 | 炮台联动 | 角落辅助敌按固定顺序施工；炮台依目标和层数调整射程；行为可预测 | 阻断 |
| Boss 房 | 潜在危险范围 | 紫色全体危险范围持续反映本回合合法施工后的潜在炮台范围，不少算、不延迟到玩家移动后才刷新 | 阻断 |
| AI | 普通敌方 | 敌人使用真实路径与攻击候选；不撞墙、不无意义接近 0 伤害目标、不漏掉合法攻击 | 阻断 |
| AI | 激活节奏 | Boss 房外守卫在自身移动后攻击范围覆盖我方时永久转主动；未触发时保持守卫 | 重要 |
| 数值 | 关卡路线 | 稳健城堡推进、优先厨房资源争夺及混合路线均至少存在一条可行解 | 重要 |
| 数值 | 难度体验 | 熟练通关约 60 分钟；初见允许更长和反复尝试，但不能依赖盲猜 | 观察 |
| 数值 | 高台风险 | 高台抬升敌人、Boss 脚下建造与四角塔台不形成唯一低风险万能解 | 观察 |
| 信息 | 单位详情 | 单位的 HP、攻击力、属性、职业、流派、技能、物品、Buff、地形和标签可查 | 阻断 |
| 信息 | 战斗预测 | 正确显示攻击顺序、HP 变化、命中、必杀、反击、追击、武器切换和主要修正来源 | 阻断 |
| 信息 | 范围显示 | 玩家/敌人移动与攻击范围、杖范围、建造/破坏目标和全体危险范围均符合实际规则 | 阻断 |
| 信息 | 情报书 | 可在非事件状态打开/关闭；开局烹饪、粉尘爆炸、Boss 房高台教学按时写入 | 重要 |
| 交互 | 撤销层级 | 目标选择取消后回到正确菜单或移动状态，不重复给予移动或行动机会 | 阻断 |
| 交互 | 事件输入 | 教学、厨师事件和重要演出期间阻止误操作；事件结束后恢复正常输入 | 阻断 |
| 表现 | 战场反馈 | 移动、攻击、反击、追击、Miss、施工、粉尘和爆炸按结算顺序清晰呈现 | 重要 |
| 表现 | 可读性 | 近、中、远镜头下单位、范围、高台层数、粉尘和交互物均可辨识 | 重要 |
| 性能 | 常规流畅性 | 1080p 下操作、镜头与敌方回合保持流畅；演出停顿与计算卡顿可区分 | 阻断 |
| 性能 | 地图刷新 | 常见危险范围、小地图、高台和粉尘刷新尽量在约 0.2 秒内完成 | 重要 |
| 兼容 | 显示模式 | 1920x1080 窗口和 F11 无边框全屏下 UI、镜头和输入正常，信息量一致 | 阻断 |
| 发布 | 资源与日志 | 无面向玩家的报错、乱码、调试标签、失效按钮或残留白盒提示 | 阻断 |
| 发布 | 导出 | Windows 导出可从启动到重开稳定运行，必要资源完整打包 | 阻断 |

## 人工完整游玩检查

每轮完整 QA 至少覆盖以下路线之一，并记录回合数、减员、存档读档、烹饪次数、爆炸次数与异常：

1. 以城堡稳步推进为主，仅有限介入厨房。
2. 优先争夺厨房，主动利用烹饪增益或粉尘爆炸。
3. 高台与远程射程控制为主的 Boss 房突破。
4. 敌方已获得多项烹饪增益后的高压残局。

## 发布前硬性检查

- 所有“阻断”条目通过。
- “重要”条目不存在已知会破坏首次体验的问题。
- “观察”条目至少完成多轮人工通关并形成明确的数值/设计结论。
- Tiled 校验、技能表校验、关卡导入和自动测试通过。
- 无未解释的 Godot Error、乱码或运行时软锁。
