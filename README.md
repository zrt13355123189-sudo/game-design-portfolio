# 张荣堂｜游戏策划作品集

这里整理我在系统与关卡设计中的完整案例，而不展示开发工程。当前主案例是回合制战棋《代号：地形》：以可改造地形和高台为核心规则，推进一张包含路线分流、厨房资源争夺与 Boss 房攻坚的单关 Demo。资料会随关卡配置、实机验证和公开素材的成熟继续修订；文中将已验证的机制、正在打磨的体验和较早期的整体游戏蓝图区分标注。

阅读方式按可用时间分层：**约 2 分钟**的机制与关卡视频正在准备，届时将从本页直达；**约 5–10 分钟**可读[《代号：地形》主案例](projects/terrain/01_项目概览.md)，理解设计问题、方案、关卡承载和迭代判断；有**约 30 分钟**时，未来可体验从完整关卡中截取的代表性试玩段落，目前尚未提供公开下载。现阶段建议先从文档进入，不将占位材料包装为可观看或可试玩成果。

针对关卡策划岗位，可从主案例继续阅读[面粉关设计](projects/terrain/03_关卡设计_面粉关.md)和[迭代复盘](projects/terrain/04_设计迭代案例.md)，重点看敌人职责、节奏组织与实机调整；针对系统策划岗位，可继续阅读[高台与地形博弈](projects/terrain/02_核心系统_高台与地形博弈.md)，重点看规则边界、跨回合收益与信息可读性。上述入口对应同一项目的不同观察角度，不是互相矛盾的两套叙述。[项目索引与阶段说明](projects/terrain/README.md)可帮助快速定位材料。简历、视频、截图、试玩包及独立游戏拆解会在具备可公开内容后补充，开发用仓库与未筛选的过程文件不在这里同步。
