**《代号：地形》是一款类《火焰纹章》的回合制战术角色扮演游戏，也是本作品集目前最完整的策划案例。** 玩家在战前编成队伍、选择流派、调整部署并消耗有限额度改造地形；进入战斗后，以移动、攻击、物品、建造、破坏和场景交互推进战局。项目以“玩家主动改变战场”为核心，高台会移动武器的最小／最大射程，面粉等关卡资源则会改变路线、时间压力与战斗解法。

## 作品集希望证明的能力

**系统设计与机制推演，是把一条规则落到玩家决策、资源交换和行动效率上。** 高台系统从“攻防兼备”的宽泛设想逐步收窄到射程几何、近战关系和高层代价；通用伤害收益被移出基础规则，转入建筑师技能，使核心机制更集中，也降低首次理解成本。

**关卡设计与玩家行为，是把抽象机制转化为敌人职责、地图空间、资源取舍与阶段节奏。** 面粉关通过厨房线和直攻城堡线组织不同的威胁到场方式，并允许战前改造、战中施工、资源运用和基本走位形成多种合理解法。

**快速验证与迭代决策，是能解释结果，也能在验证成本失控时停止。** 项目曾为高台阵地问题实现复杂的敌人空间评分；实机暴露行为难读、问题难归因、继续调参成本过高后，方案被停止并回退到更简单的敌人规则与关卡配置。

**落地与研发协同，是把策划目标拆成配置入口、规则边界和验收条件。** 公开材料重点展示设计判断；原始工作文档同时保留关卡意图、体验基线、阶段记录与验收矩阵，便于核验这些判断如何进入实际制作。
