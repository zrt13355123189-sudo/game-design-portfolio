# 张荣堂｜游戏策划作品集

2028 届，申请系统策划与关卡策划实习岗位。这里展示我作为独立 SRPG《代号：地形》主策划，从整体玩法构想、高台规则设计，到“面粉关”敌人配置和实机迭代的阶段性工作。项目的目标是让玩家主动改变战场地形，并据此重新判断射程、安全位置、资源用途和推进路线。**建议从[《代号：地形》主案例](projects/terrain/01_项目概览.md)开始**：它用约 5–10 分钟说明我面对的设计问题、做出的取舍、目前验证到哪一步，以及哪些内容仍需继续打磨。
