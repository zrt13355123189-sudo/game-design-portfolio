# 张荣堂｜游戏策划作品集

> **预计阅读：** 本页约 2 分钟　｜　**重点展示：** 项目判断、系统设计、关卡设计、实机迭代

我是 2028 届学生，目标岗位为系统策划与关卡策划。本作品集以个人原创 SRPG《代号：地形》为主案例，展示我如何把“允许玩家主动改变战场”这一构想收敛为可执行的高台规则，再通过一张大型关卡检验路线、资源、敌人职责与空间节奏；也保留了实机结果不符合预期时，如何定位问题、删减规则和停止错误方案的过程。这里不以功能数量或技术实现作为重点，而以**设计问题—判断依据—落地方式—阶段结果**组织材料。

## 主案例与个人职责

[《代号：地形》项目入口](projects/terrain/README.md)汇总了项目定位、当前进度、推荐阅读路径和素材状态。我在该个人项目中负责整体玩法构想、核心规则、关卡结构、敌人配置、配置验收与人工实机迭代。项目早期曾受到《明日方舟》高台设计的启发，目前已发展为不使用其世界观、角色或素材的原创独立游戏；本作品集讨论的是其中已经形成独立规则与关卡方法的设计实践。

## 材料边界

当前结论主要来自策划推演、最小局面实验、人工实机与项目内验收，尚未开展外部玩家测试。文档会明确区分当前版本、已放弃方案和远期方向，不把长期蓝图写成已完成内容。简历、正式试玩视频、可下载试玩包和独立游戏拆解会在材料成熟后逐步补充。
