# 张荣堂｜游戏策划作品集

> **预计阅读：** 本页约 2 分钟　｜　**重点展示：** 项目判断、系统设计、关卡设计、实机迭代

我是 2028 届学生，目标岗位为系统策划与关卡策划。主案例《代号：地形》是一款**类《火焰纹章》的回合制战棋个人项目**：玩家在方格地图上操控多名角色，围绕移动、攻击距离、反击、追击和击杀阈值规划回合；同时还可以在战前改造部分地形，并在战中建造或破坏高台，主动改变之后的射程与安全位置。

作品集记录了这个构想如何落到具体规则和关卡中，也保留了实机推演后删减机制、调整敌人配置、停止复杂 AI 方案的过程。每篇材料都按照**设计问题—具体方案—实际局面—阶段结论**展开，方便面试官直接判断我的策划思路。

## 主案例与个人职责

[《代号：地形》项目入口](projects/terrain/README.md)汇总了项目定位、当前进度、阅读路径和素材状态。我负责该项目的整体玩法构想、核心规则、关卡结构、敌人配置、配置验收与人工实机迭代。项目早期受到《明日方舟》高台设计的启发，目前已经发展为不使用其世界观、角色或素材的原创独立游戏。

## 材料边界

当前结论来自策划推演、最小局面实验、人工实机和项目内验收，尚未开展外部玩家测试。文档会分别标明现行规则、已放弃方案和远期方向，避免把长期蓝图写成完成成果。简历、正式试玩视频、可下载试玩包和独立游戏拆解会在材料成熟后继续补充。
