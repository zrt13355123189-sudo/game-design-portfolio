## 代表项目｜《代号：地形》

一款以**地形构筑、精确射程与职业流派**为核心的回合制战棋项目。

玩家不仅利用地图既有地形，还能够在战前配置地形、局内建造与破坏地形，并与同样会利用地形和关卡资源的敌人进行可预测、可复盘的空间博弈。

项目于 2026 年 3 月立项，目前核心战斗、地形改造、职业流派与单关机制已完成可玩验证，正在推进“面粉关”完整敌军节奏、路线平衡与表现层。
